# 大盘指数与市场结构分析 HTML 使用说明

> 文档版本：2026-07-15  
> 对应结构版本：`market_structure_v2`  
> 对应技术结构版本：以 `config.yaml::technical_structure` 和报告 JSON 中的算法版本为准。

本文说明“大盘指数与市场结构分析”HTML 的页面内容、各字段的意义、推荐阅读方法，以及这些结论背后的数据和判断逻辑。

阅读时请先记住三个边界：

1. 页面描述的是**截至报告日期的市场内部结构**，不是明日涨跌预测；
2. 风险、冰点、热度和修复都不是仓位或买卖建议；
3. 数据缺失或滞后时输出 `unknown`，不会自动解释为中性。

对应实现主要位于：

- `analysis/index_market_structure.py`：兼容结构指标及 v2 入口；
- `analysis/market_structure_v2.py`：v2 事实层、状态层、研究候选及质量门禁；
- `analysis/market_structure_state_v2.py`：状态分类、确认和稳定机制；
- `analysis/technical_structure/`：支撑阻力、趋势线和通道识别；
- `visual/index_forecast_report.py`：九屏 HTML 页面；
- `analysis/index_market_llm.py`：LLM 事实包和复盘总结；
- `cli/index_cli.py`：生成、归档和链接处理。

# 第一部分：页面各项内容的意义

这一部分只解释“页面上看到的内容代表什么”。计算公式和状态判断放在第二部分。

## 1. 页面标题、日期和顶部按钮

标题下方通常显示：

```text
指数代码 · 当前结构分析 · 数据截至 YYYY-MM-DD · market_structure_v2
```

它们分别表示：

- **指数代码**：当前报告的主观察指数，默认是上证指数 `000001.SH`；
- **数据截至日期**：本次结构分析实际使用的最后交易日，不是文件生成时间；
- **结构版本**：用于区分旧结构数据和当前 v2 数据；
- **查看大模型复盘总结**：打开 DeepSeek 根据同日事实包生成的文字复盘；
- **LLM 事实包**：打开交给大模型的原始结构事实，适合核对总结有没有脱离数据；
- **右上角总状态标签**：兼容版的粗粒度概括，不能替代后面 v2 的参与度、集中度、风险和修复状态。

大模型总结和事实包都会归档到同一数据日期目录。报告中的链接优先指向日期归档，不依赖根目录里的临时文件。

## 2. 第 1 屏：市场状态总览

第 1 屏回答的是：“今天市场表面上怎么走，内部又是什么结构？”

### 2.1 权重指数趋势

以沪深300为主要代表，展示日线和周线处于上升、下降还是震荡。

它用于观察大市值权重股的价格趋势。权重指数走强并不自动代表多数股票走强，所以必须和“当日赚钱效应”“分层广度”“指数与个股分化”一起看。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 上升 | 收盘价高于 MA20；MA20 相对 5 个交易日前向上；且收盘价不低于 MA60，或低于 MA60 不超过 2% |
| 下降 | 收盘价低于 MA20；MA20 相对 5 个交易日前向下；且收盘价低于 MA60 |
| 震荡 | 不满足上升或下降完整条件。它可能包含“价格快速下跌但均线斜率尚未确认转空”的过渡状态 |
| 数据不足 | 指数行情缺失、不新鲜，或均线样本不足 |

周线趋势使用周收盘、周 MA10、周 MA20 和周 MA10 斜率判断，口径见 15.3。

### 2.2 成长指数趋势

综合观察创业板指和科创50。两者方向一致时给出共同状态，不一致时显示分化。

它代表成长板块的指数趋势，不等于所有科技股、题材股或小盘股的表现。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 上升 | 创业板指和科创50在对应周期都为上升 |
| 下降 | 创业板指和科创50在对应周期都为下降 |
| 震荡 | 创业板指和科创50在对应周期都为震荡 |
| 分化 | 两个指数可用，但对应周期状态不完全一致，例如一个下降、另一个震荡 |
| 数据不足 | 两个成长指数都缺失或都不新鲜 |

因此，“分化”不是看两个指数当天涨跌是否同涨同跌，而是看它们按趋势规则得到的状态是否完全相同。

日线上升：
close > MA20
且 MA20 的 5 日斜率 > 0
且 close 不明显低于 MA60，也就是 close >= MA60 或低于 MA60 不超过 2%

日线下降：
close < MA20
且 MA20 的 5 日斜率 < 0
且 close < MA60

其余：
震荡
### 2.3 当日赚钱效应

主要概括当日多数股票是否上涨、典型股票是否赚钱，包括：

- 上涨股票比例；
- 个股收益中位数；
- 全 A 等权收益；
- 当日标准化 A/D。

指数上涨而个股中位数为负时，赚钱效应仍可能偏弱。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 强 | 上涨比例 ≥ 55%，个股收益中位数 > 0，且当日标准化 A/D > 0 |
| 强修复 | 上涨比例 ≥ 60%，个股收益中位数 > 0，全 A 等权收益 > 0，当日标准化 A/D > 0；同时 5 日或 20 日广度仍处于偏弱/弱势 |
| 中性 | 不满足强、强修复或偏弱条件 |
| 偏弱 | 上涨比例 ≤ 40%，个股收益中位数 < 0，且当日标准化 A/D < 0 |
| 数据不足 | 上游状态字段整体缺失时显示；若只是部分当日指标缺失，当前实现通常保守落到中性 |

当日赚钱效应只描述“今天多数股票是否赚钱”，不等同于中期趋势。页面允许“今天强修复，但中期市场广度仍弱”同时出现。

### 2.4 中期市场广度

观察上涨是否已经从单日反弹扩展到更稳定的中期结构，主要参考：

- MA20 上方股票比例；
- 5 日和 20 日 A/D；
- 20 日等权收益和个股中位收益；
- 20 日新高、新低范围。

“今日强修复、中期仍弱”是允许同时出现的，二者并不矛盾。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 强 | 20 日标准化 A/D、20 日等权收益、20 日个股中位收益三项中至少两项为正 |
| 中性 | 三项没有形成至少两项同向；部分关键字段缺失时也会保守落到中性 |
| 偏弱 | 三项中至少两项为负 |
| 弱势 | 满足偏弱，同时 MA20 上方比例 < 30% |
| 数据不足 | 上游状态字段整体缺失时显示 |

5 日短期广度使用同样的“三项至少两项同向”逻辑，但不额外使用 MA20 上方比例触发“弱势”。

### 2.5 尾部压力

衡量市场最弱一端有多严重，重点观察：

- 跌超 3% 和跌超 5% 股票比例；
- 近似跌停比例；
- 20 日新低比例；
- 横截面离散度；
- 近期市场波动。

尾部压力高表示大跌股票和内部破坏较多，不等于预测下一交易日继续下跌。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 较低 | 下方五类压力证据都没有进入自身历史高位 |
| 中等 | 五类证据中至少 1 类进入历史高位 |
| 较高 | 五类证据中至少 3 类进入历史高位 |
| 极端 | 五类证据中至少 4 类进入历史高位 |

五类压力证据是：跌超 5% 比例、近似跌停比例、横截面离散度、5 日市场实际波动率、20 日新低比例。这里的“历史高位”按滚动历史分位判断，当前实现使用约 90% 分位作为触发线。

横截面离散度：看同一天所有有效股票的一日收益分布有多分散。
简单说，就是今天个股涨跌差异有多大。如果很多股票都差不多涨跌，比如大多在 -1% 到 +1%，离散度低；如果一边很多股票大跌，另一边少数股票大涨，或者涨跌差距很大，离散度高。
在尾部压力里，它用于识别“市场内部撕裂”。指数可能只跌一点，但如果个股收益分布很散，说明局部风险或结构分化已经比较明显。
近期市场波动：看全市场等权收益最近几天自身波动有多大。
这里不是单只股票波动，也不是上证指数波动，而是把全 A 有效股票的等权收益当成“普通股票整体表现”，再计算最近一段时间，比如 5 日，实现波动率。它回答的是：最近几天普通股票整体表现是否忽上忽下。
### 2.6 风险扩散方向

描述风险相对前几天是在扩大、稳定、收缩还是修复。

“压力较高但正在收缩”与“压力中等但正在扩散”含义不同：前者是高位改善，后者是风险恶化的早期阶段。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 正在扩散 | 20 日新低、跌超 5%、当日 A/D、20 日 NH-NL 四类方向证据中至少 3 类恶化 |
| 正在收缩 | 四类方向证据中至少 3 类改善，且尾部压力不是较高/极端 |
| 正在修复 | 四类方向证据中至少 3 类改善，且尾部压力仍处于较高或极端 |
| 相对稳定 | 改善或恶化证据不足 3 类 |

新低和跌超 5% 下降视为风险改善；A/D 和 NH-NL 上升视为风险改善。

### 2.7 中期主导风格

显示当前相对领先的市场风格，例如权重价值、证券风险偏好、科技成长、消费、小盘题材。

它只表示横向相对强弱。某个风格“领先”可能只是跌得较少，并不保证绝对收益为正。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 全面占优 | 5 日和 20 日市场广度都为强 |
| 全面弱势 | 5 日和 20 日市场广度都偏弱/弱势，且尾部压力较高或极端 |
| 价值主导 | 20 日领涨风格是权重价值，且权重价值 20 日状态为强或跑赢 |
| 成长主导 | 20 日领涨风格是科技成长，且科技成长 20 日状态为强或跑赢 |
| 消费主导 | 20 日领涨风格是消费，且消费 20 日状态为强或跑赢 |
| 风格轮动 | 不满足以上明确主导条件 |

风格本身的 20 日状态按绝对收益和相对全 A 收益判断：≤ -3% 为弱；-3% 到 -0.5% 区间里若相对全 A 为正则为回调，否则为弱；-0.5% 到 +0.5% 为中性；≥ +2% 且相对全 A 为正为强；相对全 A 为正但绝对收益未达强势线为跑赢；其余为修复。

### 2.8 指数与个股分化

比较沪深300和全 A 等权表现，用于识别：

- `stocks_stronger`：普通股票相对更强；
- `large_cap_stronger`：权重股相对更强；
- `synchronized`：两者大致同步。

报告同时给出 1 日、5 日和 20 日视角，避免只用单日差值下结论。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 个股更强 | 全 A 等权收益 - 沪深300收益 ≥ 0.3 个百分点 |
| 权重更强 | 全 A 等权收益 - 沪深300收益 ≤ -0.3 个百分点 |
| 同步 | 两者差值在 ±0.3 个百分点以内 |
| 数据不足 | 沪深300或全 A 等权收益缺失 |

1 日、5 日和 20 日分别独立判断。第 1 屏卡片会把短中期证据合并成一句摘要。

### 2.9 市场集中度

回答“上涨和成交是由多数股票共同贡献，还是集中在少数股票和行业”。

主要状态：

| 状态 | 含义 |
| --- | --- |
| 广泛参与 | 收益和成交贡献相对分散 |
| 中度集中 | 部分集中，但仍有较广参与 |
| 高度集中 | 少数股票、行业或权重贡献占比较高 |
| 极端集中 | 上涨或成交高度依赖少数对象 |

集中度历史分位不是上涨概率，也不是风险概率。

状态展示和判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 广泛参与 | 综合集中度历史分位 < 60% |
| 中度集中 | 60% ≤ 综合集中度历史分位 < 80% |
| 高度集中 | 80% ≤ 综合集中度历史分位 < 95% |
| 极端集中 | 综合集中度历史分位 ≥ 95% |
| 数据不足 | 至少 3 类集中度证据不可用，无法计算综合分位 |

综合集中度由前 10% 股票成交占比、前三行业正贡献占比、前五行业成交占比、指数权重 HHI 等证据的历史分位合成。

### 2.9.1 指数拉升质量与成交结构

回答“指数上涨或下跌时，内部成分和成交是否同步确认”。

它支持上证指数、沪深300、上证50、中证500、中证1000、中证2000、创业板指和科创50。核心计算使用“上一可见指数权重 × 成分当日收益”估算成分对指数的贡献；若没有严格时点权重，则使用可见市值或等权近似，并在质量标记中显示 `index_weight_is_approximate` 和 `index_weight_not_point_in_time`。

主要状态：

| 状态 | 含义 |
| --- | --- |
| 广泛确认上涨 | 指数、等权和成交加权收益同向走强，正贡献不过度集中 |
| 集中但有成交支撑 | 正贡献集中在少数权重，但贡献成分成交放大，结构有确认 |
| 缩量拉权重 | 指数上涨主要来自权重正贡献，但贡献成分成交没有同步放大 |
| 掩护性上涨结构 | 指数表现好于内部多数股票，同时下跌成交或大成交承压较重 |
| 广泛下跌 | 指数、等权和成交加权收益同向走弱 |
| 多空分化 | 上述条件没有形成一致结论 |
| 数据不足 | 指数行情、成分、成交或历史样本不足 |

页面会展示质量分、掩护风险分、前 10 正贡献占比、前 10 贡献成分成交占比、下跌成交占比、大成交承压、权重 × 成交分组，以及正贡献成分和成交额前列成分表。它只描述当日结构，不预测后续涨跌，也不参与正式策略、仓位、订单或风险闸门。

### 2.10 风险阶段和持续时间

风险阶段把“当前压力水平”和“变化方向”合并为稳定状态，例如风险扩张、风险累积、高压稳定、风险收缩或风险修复。

持续时间表示该稳定状态已经维持多少个交易日。它用于区分一天噪声和持续阶段，不代表阶段一定会延续。

主要展示场景见 20.1。状态切换默认需要连续 2 个交易日确认，极端状态允许更快确认；所以第 1 屏的持续时间可能比单日原始信号更平滑。

### 2.11 确定性总结和证据展开

卡片下方的自动总结固定按以下顺序输出：

```text
赚钱效应 → 指数趋势 → 分层广度 → 集中度 → 风格 → 领涨质量 → 风险 → 修复 → 数据限制
```

证据展开区会列出当前状态、支持证据、反向证据、覆盖率、PIT 状态和置信度。这里的置信度表示证据是否完整、一致和新鲜，不是预测概率。

## 3. 第 2 屏：指数趋势与技术结构

第 2 屏回答的是：“主要指数分别多强，当前位置和技术结构是什么？”

### 3.1 主要指数表

默认观察：上证指数、沪深300、上证50、中证500、中证1000、中证2000、创业板指、科创50和同花顺全 A。

| 字段 | 意义 |
| --- | --- |
| 1/5/10/20/60 日 | 当前收盘相对相应交易日前收盘的区间收益 |
| 日线/周线 | 当前价格与均线、均线斜率形成的趋势描述 |
| 成交/20日 | 当日成交额相对最近20日平均成交额的倍数 |
| MA20/MA60 | 20日和60日简单移动平均 |
| 20/60日高低点 | 当前滚动区间的价格边界及距离 |
| 位置 | 当前更接近区间支撑、压力还是中部 |

10 日收益用于观察，不参与顶部 v2 核心状态投票。

### 3.2 指数 K 线

可以切换指数以及日 K、周 K、月 K。切换后，K 线、均线、结构线、成交量、KDJ 和 MACD 会使用同一指数、同一周期的数据一起更新。

指数使用不复权点位；全市场基准改为 `AVG_PRICE.LOCAL` 同花顺平均股价指数代理，由本地股票池 OHLC 等权平均生成，不是交易所官方可交易标的。

### 3.3 支撑阻力

显示由多个已确认高低点聚类得到的水平价格区域。

- 支撑表示历史上价格在该区域附近多次止跌或形成低点；
- 阻力表示历史上价格在该区域附近多次受阻或形成高点；
- 突破后可能发生角色互换；
- 它们是区域，不是精确目标价，也不保证反转。

### 3.4 趋势线

趋势线只保留符合常规技术分析语义的两类：

- 上升趋势线：连接逐步抬高的已确认低点，表示动态支撑；
- 下降趋势线：连接逐步降低的已确认高点，表示动态阻力。

线条被持续有效突破后会转为失效结构，而不是继续无限延长。

### 3.5 趋势通道

通道由一条有效趋势线和另一侧近似平行边界组成，用于描述价格沿某个斜率运行的区间。

通道不是两条任意平行线。另一侧需要有足够触碰，并且不能出现过多或过深的穿透。

### 3.6 结构线筛选

“支撑阻力、趋势线、通道、已失效结构”是四个独立筛选组：

- 可整组全选或清空；
- 可逐条勾选；
- 每个指数和周期分别保存当前页面会话中的选择；
- 筛选只改变显示，不重新计算行情，也不影响状态或策略。

### 3.7 成交量、KDJ、MACD

主 K 线下方一次只显示一个指标：

- **成交量**：当前周期成交量以及 5、20 周期均量；
- **KDJ**：观察短期位置和摆动强弱；
- **MACD**：观察中短期动量、趋势差和柱体变化。

这些指标只辅助读图，不进入市场广度、风险、集中度或仓位判断。

### 3.8 主要指数区间强度对比

可切换 20、60、120、250 日区间。所有指数在所选区间第一个有效交易日统一归一为 100。

它只比较区间涨跌强弱，解决不同指数绝对点位无法直接比较的问题。曲线达到 110 表示相对起点上涨约 10%，不是指数真实点位。

### 3.9 沪深300与同花顺全 A 相对强弱

该曲线高于 100 表示沪深300相对全 A 等权占优，低于 100 表示普通股票相对占优。它用于观察权重与多数股票的相对变化，不表示两者一定上涨。

## 4. 第 3 屏：分层市场广度

第 3 屏回答的是：“大盘、中盘、小盘、创业板和科创板，哪一层内部参与更强？”

### 4.1 分层对象

固定展示：

- 全 A；
- 上证50；
- 沪深300；
- 中证500；
- 中证1000；
- 中证2000；
- 创业板；
- 科创50。

各层独立计算，不能用中证1000的结果代替中证2000，也不能用指数涨跌代替成分内部广度。

### 4.2 分层表字段

| 字段 | 意义 |
| --- | --- |
| 状态 | 广泛走强、广泛走弱、修复中、分化或数据不足 |
| 有效成员 | 当日有收益且有真实成交的成分数 |
| 覆盖率 | 有效成员数占该层成分数的比例 |
| 上涨比例 | 有效成员中上涨股票占比 |
| MA20/MA60 上方 | 站在短中期均线之上的成分比例 |
| 20日新高/新低 | 突破此前20日高点或低点的比例 |
| 标准化 A/D | 上涨家数与下跌家数的净差比例 |
| 成交占比 | 该层有效成员成交额占全市场成交额比例 |
| 成员口径 | 使用的指数成分快照或回退股票池 |
| 行情新鲜度 | 对应指数行情是否新鲜 |

分层表“状态”的判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 广泛走强 | 上涨比例 ≥ 55%、MA20 上方比例 ≥ 55%、5 日 A/D > 0、MA60 上方比例 ≥ 55% 四项中至少三项成立 |
| 广泛走弱 | 上涨比例 ≤ 40%、MA20 上方比例 ≤ 35%、5 日 A/D < 0、MA60 上方比例 ≤ 35% 四项中至少三项成立 |
| 修复中 | 未达到广泛走强，但上涨比例 ≥ 55% 且 5 日 A/D > 0 |
| 分化 | 不满足广泛走强、广泛走弱或修复中 |
| 数据不足 | 上涨比例、MA20 上方比例或 5 日 A/D 缺失 |

### 4.3 市场广度明细

分层对比折线图可切换显示上涨比例、MA5/10/20/60 上方比例，以及
5/10/20/60 日新高和新低比例。新高、新低均以触发日前已经完成的对应窗口为基准，
不把触发当日纳入突破基准。

可展开查看全市场涨跌家数、有效股票数、收益中位数、等权收益、均线覆盖、A/D、新高新低、大涨大跌、近似涨跌停、离散度和波动率。

市场广度的核心用途是确认指数涨跌是否得到多数股票参与。

## 5. 第 4 屏：横截面收益分布

第 4 屏回答的是：“市场中的股票今天是普遍上涨、少数领涨、普遍下跌还是两极分化？”

### 5.1 收益直方图

横轴是当日个股收益区间，纵轴是股票数量。它展示的是当日有效股票的实际分布，不是未来收益概率分布。

### 5.2 Q10、中位数、Q90

- **Q10**：约 10% 股票低于该收益，代表左尾；
- **中位数**：典型股票表现，不受极端值过度影响；
- **Q90**：约 10% 股票高于该收益，代表右尾。

Q90 很高但中位数接近零，通常表示少数股票领涨；Q10 很低而中位数不弱，通常表示局部大跌。

### 5.3 标准差、IQR、偏度

- 标准差描述整体离散程度；
- IQR 是 Q75-Q25，描述中间 50% 股票的分散程度；
- 偏度描述收益分布向上涨或下跌尾部倾斜。

### 5.4 分布状态

页面可能显示普涨、普跌、窄幅领涨、局部下跌、两极分化、平静或数据不足。状态需要连续确认，不能把一天的异常分布直接当成新阶段。

具体判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 普涨 | 中位数 ≥ +0.8%，且上涨比例 ≥ 65% |
| 普跌 | 中位数 ≤ -0.8%，且上涨比例 ≤ 35% |
| 窄幅上涨 | Q90 ≥ +2.5%，但中位数 ≤ +0.3%，表示右尾有强股但典型股票不强 |
| 局部下跌 | Q10 ≤ -2.5%，但中位数 ≥ -0.3%，表示左尾受损但典型股票未同步恶化 |
| 两极分化 | Q90 - Q10 ≥ 6% |
| 交投平静 | 横截面标准差 ≤ 1.2% |
| 数据不足 | Q10、中位数、Q90、上涨比例或标准差缺失 |

## 6. 第 5 屏：风格轮动、领涨质量与行业结构

第 5 屏回答的是：“谁在领涨，领先是否稳定，内部质量好不好？”

### 6.1 风格强度

当前风格包括权重价值、证券风险偏好、科技成长、消费和小盘题材。

“强度”是相对强弱历史分位、内部上涨比例和 MA20 覆盖的组合分，范围约 0~100。它是横向温度，不是未来上涨概率。

### 6.2 风格轮动状态

| 状态 | 含义 |
| --- | --- |
| 强势加速 | 强度较高，相对强弱继续改善 |
| 强势减速 | 仍然领先，但短期斜率或加速度转弱 |
| 弱势改善 | 绝对强度较低，但短期开始修复 |
| 弱势恶化 | 5日和20日相对强弱同时走弱 |
| 中性轮动 | 没有满足更明确的方向条件 |

“领涨天数”和“20 日切换次数”用于判断风格持续性与轮动速度。

具体判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 强势加速 | 风格强度 ≥ 65，5 日相对斜率 > 0，且加速度 ≥ 0 |
| 强势减速 | 风格强度 ≥ 65，但 5 日相对斜率 ≤ 0 或加速度 < 0 |
| 弱势改善 | 风格强度 < 45，且 5 日相对斜率 > 0 |
| 弱势恶化 | 5 日相对斜率 < 0，且 20 日相对斜率 < 0 |
| 中性轮动 | 不满足以上条件 |
| 数据不足 | 强度、斜率或加速度缺失 |

### 6.3 领涨质量

领涨质量不仅看风格收益，还看内部上涨比例、MA20 覆盖、相对强弱、前 5 只股票正贡献占比和成交集中度。

| 状态 | 含义 |
| --- | --- |
| broad | 多数成员同步参与，贡献较分散 |
| moderate | 有一定内部参与，但证据不够广泛 |
| narrow | 收益由少数股票集中贡献 |
| deteriorating | 相对强度尚在，但内部广度已经转弱 |
| failed | 绝对与相对收益都弱，领涨质量失效 |

具体判断标准：

| 状态 | 判断标准 |
| --- | --- |
| broad | 20 日收益 > 0，内部上涨比例 ≥ 55%，MA20 上方比例 ≥ 55%，且前 5 只股票正贡献占比 ≤ 45% |
| moderate | 20 日收益 > 0 或 20 日相对全 A 收益 > 0，但没有达到 broad，也没有明显集中 |
| narrow | 20 日收益 > 0，但内部上涨比例 < 45% 或前 5 只股票正贡献占比 ≥ 60% |
| deteriorating | 20 日相对全 A 收益仍为正但 5 日相对全 A 收益转负，或内部广度 5 日变化 ≤ -10 个百分点 |
| failed | 20 日收益 < 0，且 5 日、20 日相对全 A 收益都 < 0；或其它条件都不满足 |
| unknown | 20 日收益、相对强弱、内部上涨比例、MA20 覆盖或贡献集中度缺失 |

### 6.4 行业结构与行业强弱榜

行业结构 v2 按 10 日收益强弱排序，并展示 5、10、20 日收益、相对平均股价 20 日收益、上涨比例、MA20 上方比例及领涨质量。

下方行业强弱榜按当日 1 日强弱排序，并展示 1、5、20 日收益、上涨比例、MA20 上方比例和成交占比变化。

强行业不一定值得追涨，弱行业也不等于立即反转。行业榜只描述当前横向结构。

点击有同花顺行业指数缓存的行业，可以查看对应行业指数 K 线、成交量、KDJ 和 MACD。

### 6.5 银行、保险与证券

三者优先使用同花顺行业指数代理：

- 银行、保险相对强而证券弱，通常更接近防御性权重占优；
- 证券相对银行走强，常见于风险偏好修复；
- 三者一起强，同时普通股票广度改善，才更接近全面风险偏好扩散。

这只是结构解释，不是因果保证。

## 7. 第 6 屏：风险、修复与探索性阶段

第 6 屏回答的是：“内部损伤有多重，风险往哪个方向变化，反弹修复到哪一步？”

### 7.1 三类风险证据族

- **极端下跌**：跌超3%、跌超5%、近似跌停；
- **内部破坏**：新低、MA20/MA50 下方比例、负 A/D；
- **失序程度**：离散度、波动率、指数与个股波动差、下跌成交占比。

三个证据族避免单一指标主导风险结论。

### 7.2 风险阶段

主要状态包括风险扩张、风险累积、高压稳定、风险收缩、风险修复和低压稳定。

风险阶段描述当前损伤水平与变化速度，不是未来下跌概率。

具体判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 风险扩张 | 5 日平滑风险分 ≥ 70，且 1 日变化 ≥ 2 或 5 日变化 ≥ 5 |
| 风险累积 | 45 ≤ 5 日平滑风险分 < 70，且 1 日变化 ≥ 2、5 日变化 ≥ 3；或 25 ≤ 风险分 < 45 且同样快速上升 |
| 高压稳定 | 45 ≤ 风险分 < 70，且没有满足风险累积或风险收缩；或风险分 ≥ 70 但变化未继续明显上升 |
| 风险收缩 | 45 ≤ 风险分 < 70，且 1 日变化 ≤ -2、5 日变化 ≤ -3 |
| 风险修复 | 25 ≤ 风险分 < 45，且 1 日变化 ≤ -1、5 日变化 ≤ -3 |
| 低压稳定 | 风险分 < 25；或 25 ≤ 风险分 < 45 但没有快速上升或下降 |
| 数据不足 | 风险分、1 日变化或 5 日变化缺失 |

### 7.3 修复阶段

| 状态 | 含义 |
| --- | --- |
| 恐慌扩张 | 高风险且风险仍在明显增加 |
| 恐慌稳定 | 高风险但暂未继续快速恶化 |
| 初步反弹 | 上涨比例或短期收益改善，风险开始下降 |
| 广度修复 | A/D、新低和均线覆盖同步改善 |
| 趋势修复 | MA20 覆盖明显恢复且风险降到较低区间 |
| 反弹失败 | 反弹后收益、广度和风险再次恶化 |
| 常态 | 没有处于上述特殊阶段 |

修复阶段只描述修复质量，不输出抄底信号。

具体判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 恐慌扩张 | 风险分 ≥ 65，且 5 日风险变化 > 2 |
| 恐慌稳定 | 风险分 ≥ 65，且 5 日风险变化 ≥ -2 |
| 初步反弹 | 5 日风险变化 < -3，上涨比例 ≥ 55%，且全 A 等权 5 日收益 > -1% |
| 广度修复 | A/D 五日斜率 > 0，20 日新低比例五日变化 < 0，且 MA20 上方比例五日变化 > 0 |
| 趋势修复 | MA20 上方比例 ≥ 55%，MA20 上方比例五日变化 > 0，且风险分 < 45 |
| 反弹失败 | 全 A 等权 5 日收益 < -2%，风险五日变化 > 0，且上涨比例 < 45% |
| 常态 | 不满足上述特殊状态 |
| 数据不足 | 风险、上涨比例、A/D、新低、MA20 覆盖或 5 日等权收益缺失 |

### 7.4 冰点、热度和其他研究候选

冰点、热度、反弹失败候选和风格延续都标记为 `exploratory_only=true`。

这些字段：

- 不进入确定性顶部总结；
- 不进入正式策略和信号；
- 不影响仓位和订单；
- 不影响 `market_risk_gate`。

## 8. 第 7 屏：流动性、贡献与集中度

第 7 屏回答的是：“成交额流向哪里，放量来自上涨还是下跌，贡献是否过度集中？”

### 8.1 流动性状态

| 状态 | 含义 |
| --- | --- |
| 普遍放量 | 成交放大且上涨成交占优，贡献较分散 |
| 集中放量 | 成交放大但集中于少数股票 |
| 抛售放量 | 成交放大且下跌成交占优 |
| 缩量反弹 | 市场上涨但成交低于常态 |
| 交投平静 | 缩量且等权收益波动较小 |
| 常态 | 没有出现明显异常结构 |

具体判断标准：

| 状态 | 判断标准 |
| --- | --- |
| 普遍放量 | 成交额/20 日均值 ≥ 1.10，上涨成交占比 ≥ 58%，且前 10% 股票成交占比 ≤ 45% |
| 集中放量 | 成交额/20 日均值 ≥ 1.10，上涨成交占比 ≥ 下跌成交占比，且前 10% 股票成交占比 > 45% |
| 抛售放量 | 成交额/20 日均值 ≥ 1.10，且下跌成交占比 > 上涨成交占比 |
| 缩量反弹 | 成交额/20 日均值 < 0.85，且全 A 等权收益 > 0 |
| 交投平静 | 成交额/20 日均值 < 0.75，且全 A 等权收益绝对值 < 0.5% |
| 常态 | 不满足以上异常成交结构 |
| 数据不足 | 成交额倍数、上涨/下跌成交占比、前 10% 成交占比或等权收益缺失 |

### 8.2 成交指标

- 成交额/20日均值：当前总成交相对近期常态；
- 上涨/下跌成交占比：资金主要发生在上涨股还是下跌股；
- 新高/新低成交占比：突破和破位股票占用了多少成交；
- 上涨/下跌放量行业数：放量方向在行业层面的扩散范围。

### 8.3 贡献与集中度证据

包括前10%股票正贡献占比、前10%股票成交占比、前三行业正贡献占比、前五行业成交占比、权重收益与等权收益差、指数权重 HHI。

这些指标共同判断“多数参与”还是“少数拉动”，不能只看其中一个。

## 9. 第 8 屏：市场状态历史

第 8 屏展示最近 60 个交易日的状态时间轴，包括：

- 参与度；
- 广度；
- 集中度；
- 风险；
- 领涨质量；
- 风格领导者；
- 修复阶段；
- 指数与个股分化。

相邻相同状态被合并为一个区间。表格中的“持续交易日”是当前状态连续存在的时间，“区间状态段数”可以辅助判断近阶段是否频繁切换。

时间轴由确定性规则生成，不使用 LLM 回填历史状态。

## 10. 第 9 屏：证据、来源新鲜度与时点质量

第 9 屏回答的是：“前面这些结论有多少可靠证据，哪些数据不完整？”

### 10.1 证据质量矩阵

每个状态包含：

- 当前状态；
- 置信等级和置信分；
- 独立证据族数量；
- 有效数据覆盖率；
- 数据是否新鲜；
- 是否满足 point-in-time 口径；
- 支持证据和反向证据。

置信度只衡量证据完整性、一致性和可追溯性，不表示状态未来维持的概率。

### 10.2 数据来源新鲜度

每个来源独立显示数据日期、报告日期、滞后交易日、状态和 PIT 标记。

状态含义：

- `fresh`：在该来源允许的滞后范围内；
- `stale`：数据存在但已超过允许滞后；
- `missing`：没有可用数据；
- `unknown`：无法可靠判断。

一个来源滞后不会自动污染所有模块，但依赖该来源的状态应变为 `unknown`。

### 10.3 PIT 声明和数据质量标记

PIT 声明说明历史计算是否只使用当时可见的数据。当前需要重点关注：

- 指数行情可以按日期截断；
- 指数权重使用不晚于分析日的最近快照；
- 当前股票池不是严格历史股票池；
- 当前行业分类不是严格历史行业分类；
- 历史 ST 状态覆盖有限；
- 未来行使用应始终为否。

- 市场参与、集中度、风险和修复状态；
- 正式策略、仓位和订单；
- 市场风险闸门。

`horizon` 参数只改变这个旧诊断区域的未来收益周期，不改变 v2 市场结构结论。

# 第二部分：结构分析背后的逻辑

## 12. 整体分析框架

市场结构 v2 分为三层：

```text
事实层 → 状态层 → 研究候选层
```

### 12.1 事实层

事实层只保存可核对的数字，例如收益、上涨比例、均线覆盖、新高新低、成交额、贡献占比和来源日期。

事实层不输出“看多”“看空”“建议仓位”等观点。

### 12.2 状态层

状态层把多项事实压缩为可读状态，例如广泛参与、高度集中、风险扩张、领涨转弱、广度修复。

状态必须经过：

1. 数据新鲜度检查；
2. 有效覆盖率检查；
3. 当日原始分类；
4. 连续确认和最短持有期；
5. 证据与反证记录。

### 12.3 研究候选层

冰点、热度、反弹失败和风格延续属于研究候选。它们可以用于后续验证，但当前不会进入正式结论或交易链路。

## 13. 数据来源和有效样本

| 数据 | 主要来源 | 用途 |
| --- | --- | --- |
| 指数日线 | 本地指数 CSV / Tushare | 指数趋势、相对强弱、技术结构 |
| 同花顺指数 | Tushare `ths_daily` | 全 A、风格代理、行业代理 |
| 个股日线 | 本地 A 股缓存 | 广度、收益分布、风险和成交结构 |
| 股票基础信息 | `stocks.csv` | 名称、市场、当前行业和 ST 标识 |
| 指数成分/权重 | Tushare `index_weight` | 分层广度、权重贡献和 HHI |
| DeepSeek | 同日事实包 | 文字复盘，不参与计算 |

一只股票进入当日横截面统计必须同时满足：

```text
当日收益可计算
且 amount 非空
且 amount > 0
```

停牌、缺少前收盘价、价格缺失或没有有效成交额的股票不进入当日分母，也不会被误算为平盘。

## 14. 时间边界和防未来函数

所有输入会先裁剪到 `as_of_date`。核心规则包括：

- 不读取分析日之后的指数、个股或成分数据；
- 20/60 日新高新低窗口整体 `shift(1)`，当天价格不进入自己的历史基准；
- 滚动分位只使用截至当日的历史；
- 指数成分使用不晚于分析日的最近快照；
- 周 K、月 K 技术结构默认排除未完成周期；
- 旧预测未来收益只用于底部诊断，不反向进入结构状态。

在同一份股票池和元数据快照下，裁剪未来行情后不会改变历史 T 日结果。由于当前股票池、当前行业分类和历史 ST 仍不是严格 PIT，更换元数据快照后重新回算的结果仍可能发生变化；页面会把这类限制明确标出。

## 15. 指数趋势和相对强弱逻辑

### 15.1 区间收益

```text
N日收益 = 当前收盘 / N个交易日前收盘 - 1
```

### 15.2 日线趋势

```text
上升：close > MA20，MA20的5日斜率 > 0，且 close >= MA60 或 close / MA60 - 1 >= -2%
下降：close < MA20，MA20的5日斜率 < 0，且 close < MA60
震荡：其余情况
```

### 15.3 周线趋势

周线以周收盘、周 MA10、周 MA20 和 MA10 斜率判断：

```text
上升：周收盘 > 周MA10，周MA10的2周斜率 > 0，且周收盘 >= 周MA20
下降：周收盘 < 周MA10，周MA10的2周斜率 < 0，且周收盘 < 周MA20
震荡：其余情况
```

页面兼容趋势表可能使用进行中周线；技术结构模块则默认排除未完成周线，两者用途不同。

### 15.4 归一化强度

```text
归一化值_t = 当前收盘_t / 区间首个有效收盘 × 100
```

因此各指数可以放在同一尺度比较，曲线差异只反映所选区间相对涨跌。

### 15.5 成交量、KDJ 和 MACD

成交量副图使用当前所选日/周/月周期的实际成交量，并计算 5、20 周期简单均量。周线和月线成交量是周期内日成交量求和。

KDJ 使用 `(9,3,3)`：

```text
RSV = (close - 9周期最低) / (9周期最高 - 9周期最低) × 100
K = RSV的3周期简单平均
D = K的3周期简单平均
J = 3 × K - 2 × D
```

MACD 使用 `(12,26,9)` 原始指数点位口径：

```text
DIF = EMA(close, 12) - EMA(close, 26)
DEA = EMA(DIF, 9)
MACD柱 = 2 × (DIF - DEA)
```

KDJ 和 MACD 都随指数和周期切换重新计算，不沿用上一指数的数据。

## 16. 分层广度逻辑

### 16.1 基础指标

```text
上涨比例 = 上涨有效成员数 / 有效成员数
MA20上方比例 = close > MA20 的有效成员数 / 有MA20的有效成员数
标准化A/D = (上涨数 - 下跌数) / (上涨数 + 下跌数)
```

5 日和 20 日 A/D 是每日标准化 A/D 的滚动和，不是收益率。

### 16.2 分层状态

状态同时检查上涨比例、MA20、MA60 和 5 日 A/D：

```text
偏强证据：
上涨比例 ≥ 55%
MA20上方比例 ≥ 55%
5日A/D > 0
MA60上方比例 ≥ 55%（若可用）

偏弱证据：
上涨比例 ≤ 40%
MA20上方比例 ≤ 35%
5日A/D < 0
MA60上方比例 ≤ 35%（若可用）
```

```text
broad_strength：偏强证据至少 3 项
broad_weakness：偏弱证据至少 3 项
repairing：未达到 broad_strength，但上涨比例 ≥ 55% 且 5日A/D > 0
mixed：其余情况
unknown：上涨比例、MA20上方比例或5日A/D缺失
```

每一层使用自己的成分和分母独立计算。

## 17. 集中度逻辑

集中度使用以下五类历史分位：

1. 前 10% 股票正收益贡献占比；
2. 前 10% 股票成交占比；
3. 前三行业正收益贡献占比；
4. 前五行业成交占比；
5. 指数权重 HHI。

至少三类分位有效才计算综合集中度。历史分位窗口最长 756 个交易日，最少需要 60 个有效历史样本。

```text
综合分位 < 60%       → 广泛参与
60% ≤ 综合分位 < 80% → 中度集中
80% ≤ 综合分位 < 95% → 高度集中
综合分位 ≥ 95%       → 极端集中
```

如果没有可用历史权重，相关权重贡献字段标记为近似或缺失，不会伪造官方权重。

## 18. 收益分布逻辑

每个交易日对有效股票的一日收益计算 Q05、Q10、Q25、中位数、Q75、Q90、Q95、标准差、IQR 和偏度。

主要状态条件：

```text
普涨：中位数 ≥ +0.8%，且上涨比例 ≥ 65%
普跌：中位数 ≤ -0.8%，且上涨比例 ≤ 35%
窄幅领涨：Q90 ≥ +2.5%，但中位数 ≤ +0.3%
局部下跌：Q10 ≤ -2.5%，但中位数 ≥ -0.3%
两极分化：Q90 - Q10 ≥ 6%
平静：横截面标准差 ≤ 1.2%
```

样本少于 20 只或数据不新鲜时输出 `unknown`。

## 19. 风格轮动和领涨质量逻辑

### 19.1 风格强度

```text
风格强度 = 40% × 20日相对强弱历史分位
         + 30% × 内部上涨比例
         + 30% × MA20上方比例
```

同时计算 1/5 日强度变化、5/20 日相对斜率和加速度，用于区分强势加速、强势减速、弱势改善与弱势恶化。

风格轮动状态：

```text
strong_accelerating：强度 ≥ 65，5日相对斜率 > 0，且加速度 ≥ 0
strong_decelerating：强度 ≥ 65，且 5日相对斜率 ≤ 0 或加速度 < 0
weak_improving：强度 < 45，且 5日相对斜率 > 0
weak_deteriorating：5日相对斜率 < 0，且20日相对斜率 < 0
neutral_rotation：其余情况
unknown：强度、斜率或加速度缺失
```

风格周期状态：

```text
weak：绝对收益 ≤ -3%；或 -3% < 绝对收益 < -0.5% 且未跑赢平均股价
pullback：-3% < 绝对收益 < -0.5%，但相对平均股价收益 > 0
neutral：-0.5% ≤ 绝对收益 < +0.5%
strong：绝对收益 ≥ +2%，且相对平均股价收益 > 0
outperforming：绝对收益 ≥ +0.5%，且相对平均股价收益 > 0，但未达到 strong
recovering：绝对收益 ≥ +0.5%，但未跑赢平均股价
unknown：绝对收益缺失
```

### 19.2 领涨质量

领涨质量综合：

- 5日、20日绝对收益；
- 5日、20日相对平均股价收益；
- 内部上涨比例；
- MA20 上方比例；
- 前 5 只股票正贡献占比；
- 内部广度变化。

例如风格 20 日收益为正，但内部上涨比例低于 45% 或前 5 只贡献超过 60%，会更接近 `narrow`；相对强度仍高但广度五日明显下降时，可能进入 `deteriorating`。

具体状态：

```text
failed：20日收益 < 0，且5日/20日相对平均股价收益都 < 0
deteriorating：20日相对平均股价收益 > 0 但5日相对平均股价收益 < 0；或内部广度5日变化 ≤ -10个百分点
broad：20日收益 > 0，内部上涨比例 ≥ 55%，MA20上方比例 ≥ 55%，前5只正贡献占比 ≤ 45%
narrow：20日收益 > 0，且内部上涨比例 < 45% 或前5只正贡献占比 ≥ 60%
moderate：20日收益 > 0 或20日相对平均股价收益 > 0，但没有达到 broad/narrow/deteriorating
unknown：核心输入缺失
```

## 20. 风险证据和风险阶段逻辑

### 20.1 三个风险分数

极端下跌、内部破坏和失序程度各自先缩放到 0~100，再在族内求均值。至少两个证据族有效才计算综合风险原始分。

```text
综合风险原始分 = 可用风险证据族分数的平均值
3日平滑 = 原始分的3日均值
5日平滑 = 原始分的5日均值
```

风险状态使用 5 日平滑值、1 日变化和 5 日变化共同判断：

```text
risk_expanding：风险分 ≥ 70，且1日变化 ≥ 2 或5日变化 ≥ 5
risk_building：45 ≤ 风险分 < 70，且1日变化 ≥ 2、5日变化 ≥ 3；
               或25 ≤ 风险分 < 45，且1日变化 ≥ 2、5日变化 ≥ 3
high_pressure_stable：45 ≤ 风险分 < 70，且未满足 risk_building/risk_contracting；
                     或风险分 ≥ 70 但没有继续明显上升
risk_contracting：45 ≤ 风险分 < 70，且1日变化 ≤ -2、5日变化 ≤ -3
risk_repairing：25 ≤ 风险分 < 45，且1日变化 ≤ -1、5日变化 ≤ -3
low_pressure_stable：风险分 < 25；或25 ≤ 风险分 < 45但未快速上升/下降
unknown：风险分或变化值缺失
```

风险分是结构压力尺度，不是未来下跌概率。

## 21. 修复阶段逻辑

修复状态同时参考：

- 5日平滑风险分和5日变化；
- 上涨比例；
- A/D 五日斜率；
- 20日新低比例变化；
- MA20 上方比例及其五日变化；
- 全 A 等权五日收益。

只有价格反弹而均线覆盖、新低和 A/D 没有同步改善时，通常仍是“初步反弹”，不会直接升级为“趋势修复”。

具体状态：

```text
panic_expanding：风险分 ≥ 65，且5日风险变化 > 2
panic_stable：风险分 ≥ 65，且5日风险变化 ≥ -2
initial_rebound：5日风险变化 < -3，上涨比例 ≥ 55%，且全A等权5日收益 > -1%
breadth_repair：A/D五日斜率 > 0，20日新低比例五日变化 < 0，MA20上方比例五日变化 > 0
trend_repair：MA20上方比例 ≥ 55%，MA20上方比例五日变化 > 0，且风险分 < 45
failed_rebound：全A等权5日收益 < -2%，5日风险变化 > 0，且上涨比例 < 45%
normal：其余情况
unknown：核心输入缺失
```

## 22. 流动性逻辑

流动性只使用真实 `amount`：

```text
成交额倍数 = 当日总成交额 / 20日平均总成交额
上涨成交占比 = 上涨股票成交额 / 全市场成交额
下跌成交占比 = 下跌股票成交额 / 全市场成交额
```

典型判断：

```text
broad_expansion：成交额倍数 ≥ 1.10，上涨成交占比 ≥ 58%，且前10%成交占比 ≤ 45%
concentrated_expansion：成交额倍数 ≥ 1.10，上涨成交占比 ≥ 下跌成交占比，且前10%成交占比 > 45%
selling_expansion：成交额倍数 ≥ 1.10，且下跌成交占比 > 上涨成交占比
shrinking_rebound：成交额倍数 < 0.85，且全A等权收益 > 0
quiet：成交额倍数 < 0.75，且全A等权收益绝对值 < 0.5%
normal：其余情况
unknown：成交额倍数、上涨/下跌成交占比、前10%成交占比或等权收益缺失
```

## 23. 状态稳定机制

状态机默认使用：

```text
普通状态切换：至少连续2日确认
最短持有：至少2个交易日
极端状态：允许快速切换
缺失数据：当日输出 unknown
```

该机制用于减少阈值附近一天一个状态的高频翻转。时间轴展示的是稳定状态，同时保留原始状态用于审计。

## 24. 证据置信度逻辑

置信分综合：

```text
35% × 独立证据族完整度
+ 25% × 数据新鲜度
+ 25% × 样本覆盖率
+ 15% × PIT质量
- 反向证据惩罚
```

```text
≥ 0.75 → high
≥ 0.50 → medium
< 0.50 → low
状态 unknown → confidence unknown
```

置信度只说明“这个状态有多少可靠证据”，不说明“这个状态未来有多大概率继续”。

## 25. 技术结构识别逻辑

### 25.1 ATR 和因果 pivot

ATR 使用 14 期 Wilder 风格平滑。pivot 必须等价格发生足够反向运动后才确认：

```text
确认阈值 = max(pivot_reversal_atr × ATR,
               pivot价格 × pivot_reversal_pct_floor)
```

`pivot_date` 是极值日，`confirmation_date` 是程序首次能确认该极值的日期。结构只能在确认日之后使用，避免未来函数。

### 25.2 水平支撑阻力

已确认 pivot 按 ATR 和价格百分比容差聚类。至少两个 pivot 才形成水平区域，区域中心按 pivot 强度加权。

水平位得分主要由触碰次数、新近程度、pivot 强度和聚类离散度组成。连续两根收盘有效越过区域及 ATR 缓冲后，才认定突破。

### 25.3 趋势线

上升趋势线只能由抬高的低点形成，下降趋势线只能由降低的高点形成。候选线需要满足最小跨度、最小锚点间隔、触碰容差、最大违规比例和最大穿透深度。

### 25.4 通道

通道必须依附有效趋势线，并在反向边界获得至少两次有效触碰。默认最多保留少量高分通道，避免图表被大量近似线覆盖。

### 25.5 多周期叠加

```text
日K：日线结构 + 周/月高分水平位
周K：周线结构 + 月线高分水平位
月K：月线结构
```

高周期斜向线不直接投影到低周期，因为“每 bar 斜率”的单位不同，直接叠加容易产生视觉误导。

### 25.6 主要配置参数

以下参数来自 `config.yaml::technical_structure`，用于解释当前默认行为；配置修改后应以实际 JSON 和配置哈希为准。

| 参数 | 日线默认 | 周线默认 | 月线默认 | 作用 |
| --- | ---: | ---: | ---: | --- |
| `pivot_reversal_atr` | 1.5 | 1.8 | 2.0 | pivot 反向确认的 ATR 倍数 |
| `pivot_reversal_pct_floor` | 2% | 4% | 8% | pivot 反向确认的最低百分比 |
| `horizontal_lookback_bars` | 500 | 260 | 180 | 水平位回看 bar 数 |
| `trendline_min_span_bars` | 20 | 8 | 5 | 趋势线最短跨度 |
| `projection_bars` | 30 | 12 | 6 | 结构线向右投影 bar 数 |
| `level_tolerance_atr` | 0.8 | 0.9 | 1.0 | 水平聚类 ATR 容差 |
| `level_tolerance_pct` | 1% | 1.5% | 2.5% | 水平聚类价格百分比容差 |
| `max_support/resistance` | 3/3 | 3/3 | 2/2 | 单周期最多保留的水平位 |
| `max_channels` | 1 | 1 | 1 | 单周期最多保留的通道数 |

突破还需要 `0.25 × ATR` 缓冲和连续 2 根收盘确认；趋势线默认允许的违规比例为 12%，通道为 8%，通道反向边界至少需要 2 次触碰。

## 26. 确定性总结、LLM 和系统隔离

结构总结由确定性模板先生成；DeepSeek 只读取已生成的事实包，把事实组织成复盘文字。

LLM 不参与：

- 历史状态生成；
- 风险分和修复状态；
- 收益预测；
- 正式策略信号；
- 仓位、订单和风险闸门。

即使 DeepSeek 调用失败，结构 HTML、JSON、CSV、事实包和提示词仍可生成；夜间验收会把“缺少成功复盘”视为自动任务未完整完成。

## 27. 日期归档和可复现性

每日归档目录使用结构数据日期：

```text
archive/market_structure_v2/YYYY-MM-DD/
```

文件名也包含同一日期，归档内容包括：

- 市场结构 HTML；
- JSON 和各主题 CSV；
- LLM 事实包、提示词、Markdown 与 HTML 总结；
- archive manifest。

manifest 记录 `schema_version`、`algorithm_version`、`config_hash`、`data_hash`、来源新鲜度、PIT 声明、文件 SHA256 和每次生成尝试。

同一日期重跑默认保留首份结构快照；如果首次 LLM 失败、后续成功，可以补齐总结链接，但不会覆盖当天已经归档的结构正文。

## 28. 当前限制和正确使用方式

### 28.1 当前限制

- 当前股票池存在幸存者偏差，历史退市股覆盖不足；
- 历史 ST 状态和 IPO 无涨跌幅阶段不完整；
- 行业历史使用当前分类回溯，行业贡献不是严格 PIT；
- 指数权重是离散快照，不是每日完整权重历史；
- 估值和外部资金接口当前为 `unknown`；
- 同花顺全 A 和风格/行业代理属于供应商口径；
- 近似涨跌停不是交易所逐股精确涨跌停复原；
- 技术线是结构拟合，不是目标价或交易信号。

### 28.2 推荐阅读顺序

1. 先看第 9 屏的数据新鲜度和 PIT 限制；
2. 再看第 1 屏赚钱效应、集中度、风险和修复；
3. 用第 3、4 屏确认上涨是否广泛；
4. 用第 5 屏确认谁在领涨、领涨是否集中；
5. 用第 7 屏确认成交是上涨扩张还是下跌扩张；
6. 用第 8 屏判断当前状态是一日噪声还是持续阶段；
7. 最后用第 2 屏技术结构观察指数位置；
8. LLM 总结只作为复盘辅助，重要结论回到事实包核对。

## 29. 生成命令和输出位置
