# 指数环境预测 P0/P1 最终研究结果（2026-07-13）

## 结论

历史样本和评估链路已经修复，但当前监督学习基线不具备替换正式规则或进入非线性模型阶段的资格。机会概率有一定收益排序能力，风险概率没有稳定尾部风险排序能力，且两者的概率校准质量均未超过先验基线。

## 数据与口径

- 标的：`000001.SH`（上证指数作为市场时钟和辅助特征）。
- 预测周期：未来 5 个交易日。
- 日期：2011-01-04 至 2026-07-10。
- 数据源：`config.yaml::data.cache_dir` 指向的本地 Tushare 股票和指数 CSV。
- 有效样本：3,689 个重叠日频样本，约当 737 个不重叠 5 日窗口。
- 股票池限制：本地缓存以当前可获得股票为主，没有完整历史退市股和历史 ST 状态，存在幸存者偏差；2011 年有效股票中位数 1,825，2026 年为 5,274。
- P1 不参与回测成交，不改变佣金 0.025%、卖出印花税 0.1%、最低佣金 5 元、滑点 0.1%、T+1 或涨跌停规则。

## 严格时间外设计

每折使用扩展训练窗口：

```text
训练集 → purge 5 日 → 验证集 63 日 → embargo 5 日 → 测试集 63 日
```

以下参数只能在训练/验证阶段得到：缺失值中位数、Winsorize 边界、均值和标准差、类别权重、L2、特征组、Platt 校准器及二维政策阈值。测试窗口目标或特征变化不能改变已经拟合的系数，自动化测试对此有保护。

## 标签与模型

机会目标只使用未来个股收益中位数和上涨比例；风险目标只使用未来 Q10、个股路径最大回撤和大跌股票比例。未来波动率、等权收益和未来广度只保留作诊断。

模型为两个独立的类别平衡 L2 逻辑回归。22 个候选特征包括趋势、标准化广度、当前风险/结构特征，以及四个预先声明的交互项。没有使用任何未来结果、标签或标签派生分数作为预测变量。

## 样本外结果

| 指标 | 机会模型 | 风险模型 |
| --- | ---: | ---: |
| 平均 AUC | 0.6041 | 0.5234 |
| 最佳简单基线平均 AUC | 0.6309 | 0.6453 |
| 逐折胜过最佳简单基线 | 37.04% | 18.52% |
| Brier Skill | -0.3773 | -0.8183 |
| Log Loss 改善 | -25.84% | -49.98% |
| ECE | 0.2218 | 0.2283 |

机会 Rank IC 为 0.1545，66.67% 测试折为正。机会最高五分位相对最低五分位的未来等权收益差为 `+0.74%`，5 日区块 Bootstrap 95% 区间为 `-0.04% ~ +1.53%`。风险概率最高组相对最低组的 Q10 差为 `-0.04%`，区间跨越 0，没有稳定尾部排序。

年度稳定性较差：机会 AUC 在 2014、2019 年低于 0.5；风险 AUC 多个年份低于 0.5。低波动状态下机会 AUC 也只有约 0.50。

## 策略增量验证

本地权益文件只覆盖两类策略：`sma_cross` 和 `multi_timeframe_volume_trend`，不足计划要求的三类。完整环境过滤的平均暴露约 31.5%，已与相同平均暴露的随机降仓对照。两种策略的收益/回撤改善方向不一致，不能证明增量来自环境择时而非降仓。

策略权益 CSV 已包含其生成时的手续费、滑点和成交约束，但现有两类策略的样本范围和股票覆盖不保证完全一致，因此结果只作诊断，不作上线证据。

## 最终决策

自动门槛审计输出：`stop_at_p1_keep_formal_signal_unchanged`。

P2 非线性模型和 P3 正式仓位接入不执行。未来只有在补齐 point-in-time 股票池、重做风险标签并使风险 AUC、逐折基线胜率、概率质量和多策略验证同时通过门槛后，才允许重新开启。
