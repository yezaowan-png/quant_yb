## 1. 研究方法与数据口径

本轮股票池按“概念候选 -> 产业链环节 -> 公司业务相关度 -> 本地数据校验”筛选。候选来源包括 Tushare 同花顺概念接口和公开资料；本地校验使用 `/Volumes/extend/quant_yb_data/meta/stocks.csv` 和 `/Volumes/extend/quant_yb_data/meta/daily_basic.csv`。最近可用 `daily_basic` 交易日为 2026-06-18。

已调用并核对的同花顺概念包括：`886069.TI 人形机器人`、`885517.TI 机器人概念`、`886008.TI 减速器`、`886102.TI 中国AI 50`、`885728.TI 人工智能`、`886033.TI 共封装光学(CPO)`、`886044.TI 液冷服务器`、`886050.TI 算力租赁`、`886108.TI AI应用`、`886015.TI 创新药`。这些概念的成分股数量很大，例如人工智能超过 1000 只、人形机器人超过 400 只，因此本报告采用精选池而不是全量概念池。

公开资料用于判断产业链方向：人形机器人资料普遍把 2026 年量产预期、Tier1、丝杠、减速器、灵巧手、传感器作为主线；AI 算力资料将 AI 芯片、服务器、光模块、PCB、液冷列为核心硬件链条；创新药资料将 ADC/双抗、出海 BD、自免/肿瘤和临床后期管线作为核心方向。

## 2. 总体配置建议

人形机器人适合按“核心零部件优先、整机跟踪验证”的方式观察。当前国内上市公司中，整机盈利弹性不一定最强，反而是减速器、丝杠、伺服电机、传感器和 Tier1 执行器更容易形成订单和单机价值量映射。

AI 适合拆成两层：第一层是算力硬件，包括芯片、服务器、光模块、PCB、液冷和IDC；第二层是应用软件，包括办公、语音、视觉、操作系统和企业云安全。硬件链业绩弹性更直接，但估值波动大；应用链商业化周期更长，需要跟踪 ARR、订阅率和行业落地。

创新药适合拆成三层：已商业化龙头、平台型 Biotech、CXO/CDMO。创新药本体看管线、适应症、临床读出、医保和海外授权；CXO/CDMO更像行业景气和全球订单的贝塔，和创新药融资周期高度相关。

## 6. 使用建议

程序使用时建议先复制或在 `config.yaml::stock_pool.path` 指向 `data/stock_pools_research_20260703.json`，再运行：

```text
python main.py backtest run --strategy multi_timeframe_volume_trend --pool 人形机器人
python main.py stats theme --pool AI --start 20260101 --end 20260618
python main.py stats theme --pool 创新药 --start 20260101 --end 20260618
```

如果希望做交叉筛选，例如 AI 和人形机器人交集，可用：

```text
python main.py backtest run --strategy multi_timeframe_volume_trend --pool 人形机器人,AI --pool-mode all
```

## 7. 风险与限制

第一，股票池是当前上市公司口径，存在幸存者偏差，未覆盖历史退市股和历史ST状态。第二，部分高弹性公司 PE 为空或极高，代表盈利未稳定或估值已经充分计入预期，回测时不能把概念热度等同于基本面兑现。第三，Tushare 同花顺概念成分较宽，很多公司只是弱相关，本报告已经人工精选，但仍需结合公告、订单、财报和客户验证持续维护。第四，本报告不改变回测成交价格、手续费、滑点、涨跌停、成交量限制或导出字段，仅新增股票池研究文件。
