# A 股市场环境预测模型：现状、失效证据与改进审查材料

## 技术结论

当前模块已经不再把上证指数未来涨跌作为唯一预测目标，而是预测未来个股横截面环境 `positive / neutral / conservative`。这个目标方向更符合仓位管理，但现有规则模型没有表现出有效预测能力：

- 2024-01-02 至 2026-07-03 的 5 日环境样本共 535 个。
- 准确率 34.0%，平衡准确率 33.4%，接近三分类随机水平。
- 环境分数与未来等权收益的 Pearson IC 为 -0.032、Rank IC 为 -0.014。
- 预测为“保守”的样本未来等权收益反而最高。
- 固定测试集 2025-2026 的准确率只有 32.1%，平衡准确率 31.3%。

最关键的工程事实是：`rule_v1` 和 `rule_h3_v2` 虽然保留了各自的旧指数规则计算，但最终 `environment_signal` 都统一由 `_environment_prediction_score()` 生成，因此当前环境预测层两种模型实际上没有区别。

这份材料的目的不是证明模型有效，而是让 GPT 找出标签、特征、规则、验证和数据层的具体缺陷，并提出可执行、可验证的改进方案。

## 1. 当前模型究竟在预测什么

预测目标不是指数点位，也不是单一指数未来涨跌，而是未来一段时间内：

- 多数股票是否具有正收益机会；
- 个股收益中位数和等权市场收益是否良好；
- 市场广度是否健康；
- 尾部亏损、最大回撤和大跌股票比例是否可控。

内部标签：

| 中文环境 | 字段值 | 仓位含义 |
| --- | --- | --- |
| 积极 | `positive` | 可以提高风险暴露 |
| 中性 | `neutral` | 保持中等风险暴露 |
| 保守 | `conservative` | 应降低风险暴露 |

当前支持未来 1、5、10、20 个交易日，实际诊断主要使用 5 日环境标签。

## 2. 环境标签生成方法

对每个历史交易日和未来 H 日窗口，系统计算：

1. `market_cap_index_return_Hd`：指数未来收益，仅作辅助诊断。
2. `equal_weight_return_Hd`：有效股票未来收益等权平均值。
3. `median_stock_return_Hd`：有效股票未来收益中位数。
4. `stock_win_rate_Hd`：未来收益大于 0 的股票比例。
5. `future_breadth_Hd`：未来 H 日标准化 A/D 累计值。
6. `return_q10_Hd`：未来个股收益的 10% 分位数。
7. `median_max_drawdown_Hd`：个股未来路径最大回撤的中位数。
8. `volatility_Hd`：未来等权市场波动率。
9. `large_decline_ratio_Hd`：未来跌幅超过阈值的股票比例。

所有子项使用滚动历史分位数转换为 0-100 分。分位数计算通过 `shift(horizon)`，只允许使用评分日当时已经走完未来窗口的历史样本。

```text
opportunity_score =
  0.35 × median_stock_return_score
+ 0.25 × equal_weight_return_score
+ 0.20 × stock_win_rate_score
+ 0.20 × future_breadth_score

risk_score =
  0.30 × downside_quantile_score
+ 0.25 × max_drawdown_score
+ 0.20 × volatility_score
+ 0.15 × large_decline_ratio_score
+ 0.10 × negative_breadth_score

environment_score =
  0.70 × opportunity_score
+ 0.30 × (100 - risk_score)
```

标签阈值：

```text
积极：environment_score >= 65 且 risk_score < 70
保守：environment_score <= 40 或 risk_score >= 80
中性：其余情况
```

指数未来收益不进入主标签得分，实际权重为 0%。风险分具有否决权。

## 3. 当前预测规则

最终环境预测只由 `analysis/index_forecast.py::_environment_prediction_score()` 产生。它不是经过训练的分类模型，而是一套人工线性打分规则。

### 3.1 预测机会分

```text
predicted_opportunity =
  0.20 × trend
+ 0.55 × breadth
+ 0.10 × liquidity
+ 0.15 × structure
```

模块输入：

- `trend`：指数偏离 MA20/MA60、MACD 差、KDJ K-D。
- `breadth`：上涨比例、MA20/50/200 上方比例、A/D、NH-NL 及其斜率。
- `liquidity`：成交额、成交量相对 20 日均值。
- `structure`：指数与等权市场差、沪深300与中证1000相对强弱。

### 3.2 预测风险分

```text
predicted_risk =
  0.35 × cross_section_volatility
+ 0.30 × large_decline_ratio
+ 0.20 × negative_normalized_ad
+ 0.15 × negative_normalized_nhnl
```

最终预测：

```text
predicted_environment =
  0.70 × predicted_opportunity
+ 0.30 × (100 - predicted_risk)
```

连续特征通过人工指定尺度线性映射到 0-100，并截断。缺失值通常填 50。权重、尺度、阈值、交互项和概率均没有从历史数据拟合。

## 4. 总体评估结果

| 指标 | 当前结果 | 解释 |
| --- | ---: | --- |
| 有效样本 | 535 | 5 日环境标签 |
| 准确率 | 34.0% | 接近三分类随机水平 |
| 平衡准确率 | 33.4% | 少数类没有额外识别能力 |
| 预测积极数 | 187 | 34.9% |
| 预测中性数 | 310 | 57.9%，明显偏向中性 |
| 预测保守数 | 38 | 7.1%，严重低估保守环境 |
| Score IC | -0.032 | 环境分越高，未来等权收益没有变好 |
| Rank IC | -0.014 | 排序能力接近零且方向略反 |
| 环境择时收益 | +27.6% | 低于同期指数买入持有 +36.5% |
| 环境择时最大回撤 | -11.7% | 好于指数 -14.7%，但收益损失明显 |
| 平均风险暴露 | 62.6% | 不是满仓比较 |

当前模型不能依据分类准确率、排序 IC 或择时超额收益证明有效。最大回撤有所降低，但还不能说明环境标签具备稳定风险识别能力。

## 5. 最严重的问题：保守组未来表现最好

| 预测环境 | 样本 | 个股收益中位数 | 等权收益 |
| --- | ---: | ---: | ---: |
| 积极 | 187 | -0.12% | +0.82% |
| 中性 | 310 | -0.37% | +0.34% |
| 保守 | 38 | +1.04% | +1.77% |

| 预测环境 | 上涨股票比例 | 尾部 Q10 | 标签命中 |
| --- | ---: | ---: | ---: |
| 积极 | 48.3% | -5.08% | 33.7% |
| 中性 | 47.9% | -5.54% | 34.8% |
| 保守 | 57.9% | -4.83% | 28.9% |

理想情况下，积极环境应当有最高的个股中位收益、等权收益和上涨比例，保守环境应当最差。当前结果相反：保守组的等权收益和上涨比例最好，尾部损失也最轻。

这说明问题可能不只是分类阈值偏差，更可能涉及：

- 预测特征方向写反或缩放不合理；
- 风险特征把恐慌末端识别为持续风险；
- 5 日市场存在明显均值回归；
- 标签机会分和预测机会分不是同一套映射；
- 风险标签同时混入“下跌风险”和“超跌修复机会”。

## 6. 时间稳定性很差

| 区间 | 样本 | 准确率 | 平衡准确率 | 积极-保守等权收益差 |
| --- | ---: | ---: | ---: | ---: |
| 2024 | 178 | 36.5% | 37.1% | -0.13% |
| 2025 | 243 | 33.3% | 28.5% | -4.62% |
| 2026 | 114 | 31.6% | 35.9% | -0.71% |
| 固定验证集 2024 | 168 | 37.5% | 36.8% | -0.24% |
| 固定测试集 2025-2026 | 352 | 32.1% | 31.3% | -1.39% |

2025 年和固定测试区间表现最差。积极与保守的未来等权收益差持续为负，没有表现出可接受的时间稳定性。

## 7. 已识别的实现和诊断缺陷

### 7.1 模型名称与实际环境预测脱钩

`rule_v1` 和 `rule_h3_v2` 都会计算各自的旧规则结果，但随后使用同一个 `_environment_prediction_score()` 覆盖 `market_score` 和 `environment_signal`。因此两种模型在环境预测层输出相同，当前模型对比没有实际意义。

### 7.2 预测规则没有针对标签拟合

标签机会分来自未来横截面收益分布的历史分位数；预测机会分却是人工线性组合。预测规则的尺度和权重没有通过环境标签优化，也没有证据证明人工权重合理。

### 7.3 特征相关性诊断受到目标派生列污染

当前诊断表顶部的以下字段来自未来结果，是环境标签的组成部分，不是预测日可用特征：

- `downside_quantile_score_5d`
- `negative_breadth_score_5d`
- `max_drawdown_score_5d`

它们与未来收益高度相关是定义导致的，不能作为可用特征重要性证据。训练矩阵、特征筛选和相关性报告都必须显式排除所有未来结果、标签和标签派生分数。

### 7.4 预测类别严重失衡

实际标签分布：

```text
positive      34.6%
neutral       33.8%
conservative  31.6%
```

预测信号分布：

```text
positive      34.9%
neutral       57.9%
conservative   7.1%
```

风险模型几乎不发出保守信号。

### 7.5 旧概率字段不对应新目标

`p_bull / p_neutral / p_bear` 来自旧指数规则分数，不能解释新的环境分类概率，也没有经过时间外校准。

### 7.6 所有预测周期共用同一规则

1、5、10、20 日环境使用同一套预测权重和阈值，没有针对不同周期分别训练或配置。

## 8. 环境过滤回测证据有限

| 策略 | 过滤前收益 | 过滤后收益 |
| --- | ---: | ---: |
| multi_timeframe_volume_trend | +0.04% | +0.29% |
| sma_cross | -6.49% | -2.73% |

| 策略 | 过滤前最大回撤 | 过滤后最大回撤 |
| --- | ---: | ---: |
| multi_timeframe_volume_trend | -1.65% | -1.28% |
| sma_cross | -20.98% | -19.10% |

| 策略 | 过滤前盈亏比 | 过滤后盈亏比 |
| --- | ---: | ---: |
| multi_timeframe_volume_trend | 0.84 | 0.88 |

这些结果来自当前目录已有权益曲线的日收益聚合，并非统一重跑的同口径组合回测。它们只能说明环境过滤可能减少部分暴露，不能证明模型具有跨策略稳健性。

需要在固定股票池、统一日期、统一手续费、统一滑点和统一策略参数下重新回测。

## 9. 数据范围和已知限制

本次评估：

- 标的：上证指数 `000001.SH`。
- 预测周期：未来 5 个交易日。
- 日期范围：2024-01-02 至 2026-07-03。
- 有效环境样本：535。
- 股票横截面来源：本地约 5,330 个股票 CSV 缓存。
- 大小盘相对强弱：沪深300与中证1000历史指数缓存。

主要限制：

- 当前股票缓存通常由当前上市列表建立，历史退市股和历史 ST 状态可能缺失，存在幸存者偏差。
- 样本只有约两年半，缺少完整牛熊周期。
- 5 日标签窗口高度重叠，连续样本并不独立。
- 当前主要只有一个指数代理和一个 5 日周期的完整诊断。
- 停牌、上市不足窗口、涨跌停和缺失收益处理可能改变横截面标签。

## 10. 建议改进顺序

### P0：先修正评估可信度

1. 从特征相关性、训练矩阵和模型输入中严格排除未来结果、标签分数及其派生列。
2. 为 1、5、10、20 日分别生成独立预测模型和时间外指标。
3. 使用 walk-forward 或 expanding-window 验证，并按 horizon 设置 purge/embargo。
4. 增加多数类、分层随机、简单趋势、简单均值回归基线。
5. 报告 macro-F1、balanced accuracy、每类 precision/recall、log loss/Brier、收益排序和风险排序。
6. 将“标签本身是否稳定”与“模型是否能预测标签”分开评估。

### P1：建立可解释监督学习基线

1. 使用带正则化的 multinomial logistic regression。
2. 所有缩放、缺失值填充和特征筛选只能在训练窗口拟合。
3. 对类别不平衡使用 class weight 或时间外阈值优化，不要简单复制样本。
4. 用时间外概率进行校准，废弃旧 `p_bull/p_bear` 作为环境概率。
5. 与当前人工规则做逐折比较，不能只比较全样本汇总。

### P1：重新审查标签设计

1. 分别检查 opportunity、risk 和最终三分类的可预测性。
2. 比较单一三分类模型与双头模型：机会概率和尾部风险概率独立预测，再由仓位层合成。
3. 检查固定 `65/40/70/80` 阈值是否造成标签不稳定。
4. 将“超跌修复”和“持续弱势”拆开，避免高风险与高反弹机会压成同一保守类。
5. 对 1、5、10、20 日使用不同的波动率、大跌阈值和预测权重。

### P2：再考虑非线性模型

1. 对比 HistGradientBoosting，但必须保留严格时间外验证。
2. 使用 permutation importance 或 SHAP 审计特征方向与稳定性。
3. 只有在多个 walk-forward 折次稳定超过逻辑回归和简单规则后，才保留非线性模型。

### P3：验证真实仓位价值

1. 用固定股票池和统一策略组合重跑环境过滤回测。
2. 比较过滤前后收益、最大回撤、Calmar、盈亏比、换手和平均暴露。
3. 检查积极转保守、保守转积极之后 1/5/10/20 日策略表现。
4. 要求环境信号对多个策略和多个市场阶段有一致增量价值。

## 13. 不确定性与审阅边界

这是一份描述性和诊断性报告，不证明因果关系。本文没有重新训练机器学习模型，也没有重新运行统一口径的全市场策略回测。

由于样本较短、股票池存在幸存者偏差、标签窗口重叠，所有数值应被视为发现问题的证据，而不是模型上线依据。
