# 市场环境预测模型 P0 第一轮改进计划

> 来源：2026-07-13 GPT 外部审阅反馈，并补充“恢复大样本历史覆盖”的要求。

## 1. 总体结论

当前问题不是继续微调 `_environment_prediction_score()` 权重，而是存在三个结构性错位：

1. 当前市场压力可能代表风险延续，也可能代表恐慌末端；现有规则没有区分二者。
2. 标签由未来横截面结果的滚动分位数生成，预测器却是未经拟合的人工线性缩放。
3. 机会与风险内部指标高度重复，并被压缩成单一三分类，损失了二维信息。

推荐长期方向：分别预测未来赚钱机会和未来下行风险，再由仓位政策层合成环境。

## 2. 新增要求：恢复足够的历史样本

当前报告只有 535 个 5 日样本，原因之一是预测输出曾以 `--start 20240101` 生成，而后续诊断复用了不覆盖 2011 起始日期的旧文件。

第一轮要求：

- 默认使用 `config.yaml::defaults.start_date`，当前为 `20110101`。
- 诊断发现已有 features/predictions 不覆盖请求区间时，必须自动重建，不得静默复用短区间文件。
- 报告必须同时显示：日频重叠样本数、约当不重叠样本数、起止日期。
- 5 日模型的约当不重叠样本数按 `floor(sample_count / 5)` 仅作保守提示，不代替正式区块统计。
- 样本恢复后仍须使用 purge/embargo，不能因为追求数量而放松未来函数约束。

第一轮验收：

- 真实 `000001.SH` 5 日环境诊断覆盖 2011 至当前缓存末日。
- 有效日频样本显著高于 535。
- 预测文件覆盖不足时自动刷新有测试保护。

## 3. P0 第一轮实施范围

### 3.1 修复评估可信度

- 建立集中式目标/泄漏列识别函数。
- 从特征相关性、模型矩阵、特征筛选中排除：
  - 所有未来收益和未来横截面结果；
  - 所有标签；
  - opportunity/risk/environment 标签得分；
  - `downside_quantile_score_*`、`max_drawdown_score_*` 等目标派生列；
  - 旧 `p_bull/p_bear`；
  - 原始指数点位、原始成交量绝对值和累计 A/D/NH-NL 绝对值。
- 诊断报告输出实际进入可训练矩阵的白名单字段。

### 3.2 增加 A/D、NH-NL“水平 × 变化方向”事件研究

对以下组合进行二维分组：

```text
normalized_ad 水平分位 × ad_slope_5 改善/恶化
normalized_nhnl 水平分位 × nhnl_slope_5 改善/恶化
```

每组统计未来 H 日：

- 个股收益中位数；
- 等权收益；
- 上涨股票比例；
- Q10；
- 样本数。

核心验证：

```text
极弱 + 继续恶化 -> 是否对应风险延续
极弱 + 开始改善 -> 是否对应超跌修复
```

### 3.3 建立双目标、低复杂度基线

不再直接拟合最终三分类，第一轮分别建立：

- 机会目标：未来个股收益中位数/上涨比例是否进入历史高机会区。
- 风险目标：未来 Q10、最大回撤和大跌股票比例是否进入高风险区。

首选模型：标准化 + L2 二元逻辑回归。若不引入外部依赖，则使用项目内可审计的 NumPy 实现。

第一轮特征控制在约 12-20 个：

- 指数 5/20 日收益、距 MA20/MA60、MA20 斜率、标准化 MACD 柱；
- normalized A/D、A/D 5/20 日斜率；
- normalized NH-NL、NH-NL 5/20 日斜率；
- MA20/MA200 上方比例；
- 横截面波动率、大跌股票比例；
- 指数与等权 5 日差、大小盘 10 日相对强弱；
- 少量“水平 × 斜率”交互项。

### 3.4 Purged walk-forward 时间外验证

时间定义：

```text
特征时间：t 日收盘后
标签窗口：t+1 至 t+H
信号执行：t+1 日开盘或后续明确的可成交价格
```

第一版扩展窗口：

```text
初始训练：至少 252 个交易日
测试：63 个交易日
每 63 个交易日向前滚动
训练末端 purge = H
相邻调参与测试之间 embargo >= H
```

每折的缺失值中位数、均值、标准差、Winsorize 边界、正则化参数、类别权重和阈值只能由训练窗口拟合。

输出：

- 每折起止日期和样本数；
- 机会模型 AUC、Rank IC、分组收益；
- 风险模型 AUC、高低风险组 Q10/回撤差；
- 时间外概率和二维仓位环境；
- 与多数类、简单趋势、简单均值回归和当前人工规则比较。

## 4. 标签研究方向

第一轮保留当前标签用于对照，同时增加透明标签：

```text
机会标签 A：只用未来个股收益中位数
机会标签 B：只用未来上涨股票比例
风险标签 C：只用未来 Q10 / 最大回撤
```

建议的精简连续目标：

```text
future_opportunity =
0.60 × 个股收益中位数分位数
+ 0.40 × 上涨股票比例分位数

future_downside_risk =
0.45 × Q10 损失分位数
+ 0.35 × 个股最大回撤分位数
+ 0.20 × 大跌股票比例分位数
```

未来波动率移出风险标签，作为不确定性指标；等权收益保留为诊断；未来广度不与上涨比例重复计分。

## 5. 第一轮暂不做

- 不继续调人工规则权重。
- 不上 HistGradientBoosting、XGBoost 或复杂神经网络。
- 不用随机过采样破坏时间结构。
- 不把重叠日频样本当作 IID 样本解释显著性。
- 不直接把新环境信号接入真实策略默认仓位。

## 6. 第一轮停止条件

出现任一情况时暂停复杂建模：

- 简化标签无法形成可解释的机会和风险排序；
- point-in-time 股票池问题使历史结果不可用；
- 大多数 walk-forward 折不优于简单基线；
- 机会 OOS IC 接近 0，或风险 AUC 低于 0.55；
- 标签对轻微权重变化极度敏感；
- 不同年份标签分布严重漂移且无稳定经济解释。

## 7. 后续上线研究门槛

初始研究门槛：

- Balanced Accuracy、Macro-F1 至少超过最佳简单基线 3 个百分点。
- 至少 70% walk-forward 测试折优于基线。
- 机会 OOS Rank IC > 0.03，至少 70% 折为正。
- 风险模型 AUC >= 0.60，高风险组尾部损失明显恶化。
- 相同平均风险暴露下，最大回撤相对下降至少 10%，Calmar 提升至少 15%。
- 至少三种不同逻辑策略上方向一致。

## 8. 第一轮实际修改记录

2026-07-13 第一轮已完成以下落地与验证：

- 诊断命令会检查已有预测文件是否覆盖请求区间；短区间文件不再被静默复用，并增加自动重建测试。
- `000001.SH`、H=5、2011-01-04 至 2026-07-10 的真实缓存验证得到 3,689 个有效日频样本，约当 737 个不重叠窗口；原短区间为 535 个样本。
- 统一目标/泄漏列识别，并输出 22 个字段的 P0 固定特征白名单（18 个原始特征和 4 个有经济含义的交互项）；未来收益、标签及其 opportunity/risk 派生分数不再进入相关性或模型矩阵。
- 新增 A/D、NH-NL“历史水平分位 × 5 日斜率方向”事件研究 CSV。当前结果并不支持简单地把“极弱且改善”一律解释为反转，后续需按年份、市场状态和有效股票数复核稳定性。
- 新增 NumPy 实现的标准化、类别平衡、L2 双逻辑回归基线；扩展训练窗口、每折 63 日测试、训练末端 purge=H，输出逐折预测。
- 全历史清洗后结果：55 折均有有效指标，机会模型平均 AUC 约 0.601，风险模型约 0.507；当前人工规则命中率 28.3%、平衡命中率 31.2%、积极与保守组未来等权收益差为 -0.26%。

结论：第一轮达到了“恢复样本、清理评估、建立可证伪基线”的目的，但没有达到上线门槛。

## 9. 剩余计划完成情况（P0/P1）

2026-07-13 已继续完成原审阅意见中剩余的 P0/P1 项目：

- 标签改为每折训练窗内根据原始未来结果生成，加入透明的 A（收益中位数）、B（上涨比例）、C（Q10/最大回撤）标签；未来波动率和未来广度不再进入 P1 风险/机会目标。
- 时间折改为 `训练 → purge=H → 验证63日 → embargo=H → 测试63日`。测试前冻结训练中位数、1%/99% Winsorize、标准化、类别权重、L2、Platt 校准和二维政策阈值。
- L2 在 `[0.01, 0.1, 1, 10]` 中由验证窗选择；趋势、广度、风险/结构三组消融选择也只能在验证窗完成。
- 加入多数类先验、按训练比例确定性随机、趋势、均值回归、仅 A/D、仅 NH-NL 的逐折基线；输出 Brier Skill、Log Loss 改善、ECE、Macro-F1、Balanced Accuracy。
- 二维政策阈值在验证窗中优先满足“保守召回率不低于 45%，精确率不低于保守基础发生率”，再优化 Macro-F1；若没有候选满足，明确记录约束失败。
- 加入逐折系数及方向稳定性、标签轻微权重敏感性、年度/波动状态稳定性、单变量十分位、区块 Bootstrap、环境切换事件和 point-in-time 股票数覆盖审计。
- 加入策略 A-E 对照：不降仓、指数趋势、市场广度、完整环境、相同平均暴露的随机降仓；所有仓位滞后一天执行。
- `rule_v1` 与 `rule_h3_v2` 的环境层实际共享同一规则，输出新增 `environment_model=shared_environment_rule_v1`，诊断名称不再暗示两者是不同环境模型。

全历史最终结果（`000001.SH`、H=5、2011-01-04 至 2026-07-10、本地 Tushare CSV）：

| 门槛 | 实际 | 要求 | 结果 |
| --- | ---: | ---: | --- |
| 机会 Rank IC | 0.1545 | >= 0.03 | 通过 |
| 机会 IC 为正折比例 | 66.67% | >= 70% | 未通过 |
| 风险 AUC | 0.5234 | >= 0.60 | 未通过 |
| 机会/风险逐折胜过最佳简单基线 | 37.04% / 18.52% | >= 70% | 未通过 |
| 机会/风险 Brier Skill | -0.3773 / -0.8183 | > 0 | 未通过 |
| 机会/风险 ECE | 0.2218 / 0.2283 | <= 0.08 | 未通过 |
| 策略数量 | 2 | >= 3 | 未通过 |

机会最高组相对最低组未来等权收益差为 `+0.74%`，但 5 日区块 Bootstrap 95% 区间为 `-0.04% ~ +1.53%`，尚未排除负值；风险高低组 Q10 差接近 0，未形成风险排序。

## 10. P2/P3 决策

门槛审计结论为：

```text
stop_at_p1_keep_formal_signal_unchanged
```

因此计划中的 P2 非线性模型和 P3 上线接入被正式否决，而不是遗留未实施：风险 AUC 低于停止条件、绝大多数折未胜过简单基线、概率质量为负，且历史股票池存在无法由当前缓存修复的退市股/历史 ST 幸存者偏差。在这些条件下继续训练 HistGradientBoosting/SHAP 或替换正式仓位属于违反停止条件并增加过拟合风险。

正式 `index forecast` 信号和回测成交约束保持不变；P1 结果只作为诊断产物保存。若未来补齐 point-in-time 股票池并重新定义风险标签，必须重新从 P0 门槛开始验证。
