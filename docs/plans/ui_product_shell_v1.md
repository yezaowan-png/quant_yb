# Dashboard 产品壳 v1

## 目标

将 `dashboard.html` 收敛为 QuantYB 的产品入口，只负责读取已经生成的本地报告并提供导航。该页面不下载数据、不运行统计、不刷新市场结构或个股页面。

## 导航映射

| 原有分散入口 | 新产品入口 | 处理方式 |
| --- | --- | --- |
| 数据质量报告 | 数据中心 | 保留原报告链接，仅展示本地审计状态与覆盖率摘要。 |
| 市场概览、市场结构摘录 | 市场环境 | 保留原报告链接，不改变报告文件名或命令。 |
| 指数、行业、概念、股票查看器 | 行情中心 | 作为同一入口下的指数、行业、主题、个股、自选标签。 |
| 强势股雷达 | 强势方向 | 保留原雷达页面，首页只读取少量强势状态摘要。 |
| 策略和筛选报告 | 策略选股 | 仅显示开发中边界，不把研究结论包装为交易入口。 |
| 回测、ETF、RPS、形态、涨停、市场风险、预测、支撑压力、优化审计、旧总面板 | 研究工具 | 从主导航移出，仍提供原始报告链接。 |

## 保留与兼容

- `visual.dashboard.generate_dashboard` 保持原有行为，作为旧总面板生成器。
- 新 CLI 默认生成只读产品壳；首次覆盖已有 `dashboard.html` 前会复制旧文件为 `legacy_dashboard.html`。
- `dashboard --legacy` 仍可显式生成旧总面板到 `legacy_dashboard.html`。
- 不变更 CLI 之外的命令、报告文件名、数据格式、RS/策略/风险计算、主题池或数据下载流程。

## 验证

1. 新页面包含约定的六个主导航和独立研究工具区。
2. 已生成页面均使用相对链接，缺失页面显示“待生成”及对应命令。
3. 生成产品壳不会修改已有报告，也不会调用数据或报告生成器。
4. 原 dashboard 生成器及既有测试仍可直接使用。
