# 大盘指数分析计划

## 目标

建立一个“大盘环境分析”系统，用于判断当前市场是真强、虚强、震荡还是弱势，并辅助后续题材分析、买点扫描和仓位控制。

核心问题：

1. 大盘现在强不强？
2. 是真强还是虚强？
3. 强在哪里：权重、成长、中小盘、题材？
4. 当前适合积极做多、轻仓试错，还是防守？

第一版继续使用：

```text
quant> index market
```

输出：

```text
output.reports_dir/market_overview.html
```

广度类领先指标的呈现原则：

- NH-NL 和腾落指数 A/D 不做顶部卡片，避免把时间序列指标压扁成单日数值。
- `000001.SH` 上证指数概览的日 K 指标区增加 A/D 和 NH-NL 副图，表现形式类似 MACD/KDJ/RSI。
- `market_overview.html` 同步展示一份上证广度指标区，并在 A/D、NH-NL 上方显示上证指数 K 线，方便价格与广度背离对照。
- 其他指数概览暂不增加 A/D 和 NH-NL 副图。
- 分层 A/D 第一版展示全A、沪深300、中证1000、中证2000、创业板全板块。

## 分析框架

大盘强弱不只看指数当天涨跌，而是综合：

- 指数自身趋势
- 成交量能
- 市场广度
- 主线结构
- 关键位置有效性
- 指数相对强弱
- 风险偏好

最终形成一个 100 分制大盘强弱评分。

## 一、指数自身趋势

目标：判断指数形态强弱。

主要指标：

| 状态 | 含义 |
| --- | --- |
| 指数在 5日、10日、20日线上方 | 短线偏强 |
| 指数在 20日、60日线上方 | 中期偏强 |
| 20日线 > 60日线 > 120日线 | 多头结构 |
| 指数跌破 20日线但守住 60日线 | 强势震荡 |
| 跌破 60日线并且反抽不上去 | 转弱 |
| 60日线、120日线向下 | 中期弱势 |

需要覆盖的指数：

- 上证指数
- 沪深300
- 创业板指
- 科创50
- 中证500
- 中证1000
- 中证全指

输出标签：

```text
趋势偏强 / 强势震荡 / 震荡 / 转弱 / 中期弱势
```

## 二、成交量能

目标：判断上涨是否有资金确认。

主要指标：

- 当日成交额 vs 20 日均成交额
- 近 5 日平均成交额 vs 20 日平均成交额
- 上涨日是否放量
- 下跌日是否缩量
- 突破 MA20 或前高时是否放量
- 高位放量但涨幅不足时，标记为放量分歧

强势特征：

- 放量上涨
- 缩量回调
- 突破关键位置时明显放量
- 成交额持续维持较高水平

弱势特征：

- 缩量上涨
- 放量下跌
- 反弹一天就没量
- 高开低走、冲高回落频繁

输出标签：

```text
放量上涨 / 缩量反弹 / 放量下跌 / 缩量回调 / 高位分歧
```

## 三、市场广度

目标：判断指数上涨是否由多数股票支持，这是识别真强和虚强的核心。

第一版从本地股票 K 线缓存计算：

- 上涨家数
- 下跌家数
- 平盘家数
- 上涨占比
- A/D：上涨家数 - 下跌家数
- A/D 线：每日 A/D 值累计线
- 标准化 A/D：(上涨家数 - 下跌家数) / (上涨家数 + 下跌家数)
- 标准化 A/D 线：每日标准化 A/D 值累计线，减少上市公司数量变化造成的长期尺度漂移
- 起点归零标准化 A/D 线：把每个分层的累计标准化 A/D 线减去本窗口首日值，用于更清楚比较斜率和近期变化
- 分层标准化 A/D：全A、沪深300、中证1000、中证2000、创业板分别计算，用于区分权重行情、普涨行情和小票/成长股赚钱效应
- 个股站上 MA20 的比例
- 个股站上 MA60 的比例
- 一年新高股票数
- 一年新低股票数
- NH-NL：一年新高股票数 - 一年新低股票数
- NH-NL 5 日加总：用于近似周度新高－新低指数

典型判断：

```text
指数上涨 + 上涨家数多 = 真强
指数上涨 + 下跌家数多 = 权重护盘 / 虚强
指数下跌 + 上涨家数多 = 结构活跃
指数下跌 + 下跌家数多 = 普跌弱势
指数上涨 + A/D线同步走强 = 多数股票跟涨，上涨健康
指数上涨 + A/D线走弱 = 少数权重拉指数，警惕假强
指数下跌 + A/D线提前走强 = 下跌扩散减弱，留意反弹线索
长期观察优先看标准化 A/D线；分层横向对比优先看起点归零标准化 A/D线，短期观察可同时参考每日广度柱
沪深300标准化A/D线走强但全A走弱 = 权重行情
全A和指数同步走强 = 普涨行情
指数上涨但中证1000/创业板标准化A/D线走弱 = 小票或成长股不跟
指数创新高 + NH-NL 没有同步走强 = 领涨力量减弱
指数下跌 + NH-NL 不再创新低 = 杀跌力量减弱
```

## 四、指数相对强弱

目标：判断市场由哪类资产主导。

| 指数 | 代表含义 |
| --- | --- |
| 上证指数 | 传统大盘、金融、资源、央国企权重 |
| 沪深300 | 核心蓝筹、大市值资产 |
| 创业板指 | 成长股、新能源、医药、科技 |
| 科创50 | 硬科技、半导体、创新成长 |
| 中证500 | 中盘股 |
| 中证1000 | 小盘股 |
| 中证全指 | 全市场真实表现 |

判断方式：

- 沪深300强，中证1000弱：权重强，小票弱
- 创业板强，上证弱：成长强，传统蓝筹弱
- 中证1000强，沪深300弱：小盘题材活跃
- 全部指数共振上涨：市场真正强
- 指数分化严重：结构性行情，不是全面牛市

输出标签：

```text
权重主导 / 成长主导 / 小盘题材主导 / 全市场共振 / 指数分化
```

## 五、主线结构

目标：判断有没有持续赚钱效应的主线方向。

第一版先基于现有题材池，不额外引入行业指数：

- 每个题材近 5 日、20 日平均涨跌
- 题材上涨占比
- 题材内站上 MA20 比例
- 题材是否连续 3 日跑赢中证全指或沪深300
- 是否有多个题材同时走强

输出标签：

```text
主线清晰 / 主线分化 / 热点轮动 / 无明显主线
```

## 六、关键位置

目标：判断突破是真突破还是假突破。

关键位置包括：

- 前高
- 前低
- 平台压力位
- 箱体上沿/下沿
- 20日线、60日线、120日线、250日线
- 缺口位置
- 大阴线高点
- 大阳线低点

第一版先做均线和近 20/60 日高低点：

- 突破 20 日高点是否放量
- 突破后是否收盘站稳
- 跌破 MA20 后是否快速收回
- 回踩 MA20/MA60 是否有效

## 七、风险偏好

目标：判断资金是否愿意追高和承担风险。

第一版简化处理：

- 大跌家数比例
- 创新低数量
- 指数高位放量滞涨
- 中证1000、创业板是否明显弱于沪深300

后续如果数据源稳定，再接：

- 涨停数量
- 跌停数量
- 连板高度
- 炸板率
- 高位股亏钱效应

## 八、大盘强弱评分

满分 100 分：

| 模块 | 分值 |
| --- | -: |
| 指数趋势 | 25 |
| 成交量能 | 20 |
| 市场广度 | 20 |
| 相对强弱 | 15 |
| 主线结构 | 15 |
| 风险情绪 | 5 |

分数解释：

| 分数 | 市场状态 | 操作含义 |
| --- | --- | --- |
| 80 分以上 | 强势市场 | 可积极做多，重视主线 |
| 60-80 分 | 震荡偏强 | 控制仓位，做强势板块 |
| 40-60 分 | 震荡市 | 轻仓，快进快出 |
| 20-40 分 | 弱势市场 | 防守为主 |
| 20 分以下 | 极弱市场 | 少做或空仓观察 |

## 看板呈现

`market_overview.html` 建议分 6 块：

1. 顶部总览
   - 总分
   - 市场状态
   - 核心结论

2. 指数强弱表
   - 指数
   - 近 5 日
   - 近 20 日
   - MA20
   - MA60
   - MA120
   - 成交额状态
   - 趋势标签
   - 评分

3. 市场广度
   - 上涨家数
   - 下跌家数
   - 平盘家数
   - 上涨占比
   - A/D 副图
   - A/D线副图
   - MA20 上方股票比例
   - MA60 上方股票比例
   - 一年新高数
   - 一年新低数
   - NH-NL
   - NH-NL 5日加总

4. 量能判断
   - 指数成交额是否放大
   - 上涨是否有量
   - 下跌是否缩量
   - 是否放量滞涨

5. 主线题材
   - 题材
   - 近 5 日涨跌
   - 近 20 日涨跌
   - 上涨占比
   - 是否跑赢指数
   - 主线强度

6. 风险提示
   - 指数红但下跌家数较多，提示权重护盘
   - 创业板和中证1000弱于沪深300，提示风险偏好不足
   - 成交额未放大，提示反弹持续性不足

## 实施顺序

### 第一步：强化当前 `index market`

目标：把现有大盘看板升级成评分系统。

任务：

- 增加 100 分评分
- 增加趋势标签
- 增加量能标签
- 增加广度标签
- 增加相对强弱标签
- 增加真强/虚强判断

不引入新接口，优先使用现有指数缓存和股票 K 线缓存。

### 第二步：加入广度细节

目标：让“指数强但个股弱”的识别更准。

任务：

- 计算 MA20 上方股票比例
- 计算 MA60 上方股票比例
- 计算 A/D 和 A/D 线
- 计算一年新高数量
- 计算一年新低数量
- 计算 NH-NL 和 NH-NL 5 日加总
- 增加每日上涨/下跌/平盘趋势图

### 第三步：接题材主线

目标：把大盘分析和题材池串起来。

任务：

- 题材近 5 日、20 日强弱
- 连续跑赢指数天数
- 题材内上涨占比
- 题材主线评分

### 第四步：补情绪数据

目标：提升风险偏好判断。

候选指标：

- 涨停数量
- 跌停数量
- 连板高度
- 炸板率
- 高位股亏钱效应

这部分需要确认数据源稳定性，不建议第一版就上。

## 第一版建议落地范围

优先做第一步和第二步：

```text
升级 index market：
1. 加大盘 100 分评分
2. 加趋势/量能/广度/相对强弱标签
3. 加 MA20/MA60 股票占比
4. 在上证指数和 market overview 中加入 A/D、标准化A/D线、NH-NL、NH-NL 5日副图
5. 看板顶部输出“真强/虚强/震荡/弱势”判断
```

第一版不改变回测策略、不改变交易流水、不改变现有 CSV 字段，只增强指数分析看板。
